# ポケモンセンターオンライン: 配送型抽選の実取得検証

公式トップから最新のポケカ抽選案内を発見し、HTMLと日程画像を通常HTTPで取得するdry-runです。
公開スナップショット、本番DB、利用者の応募済み・お気に入りは変更しません。定期実行はありません。

必要環境: Node.js 22、Python 3 + Pillow、Tesseract 5 + 日本語データ。
GitHub Actionsは手動実行と検証コード変更時のpushだけです。

画像の横罫線・縦罫線から4項目・2列の表を識別し、商品見出しと各セルを別々にOCRします。
日時は2つのOCRモードで照合し、日付の存在・曜日・期間順序・必要な時刻を検算します。
罫線のない表、項目が異なる表、読み取れない表は失敗にします。値を補って成功にしません。
画像に年がない場合は公式案内の掲載年を補助値として使用し、INFERREDとyearBasisを記録します。
掲載年と画像の曜日が一致しない日程や、年をまたぐ期間は確定しません。
「以降」は下限、「発送予定」は予定期間として保持し、発送時刻は補完しません。
同じ誤読が2モードで一致する可能性は残るため、2モード一致だけで抽出精度を保証しません。

取得は独立した2プロセスで20秒あけて実施し、値と本文・画像ハッシュを比較します。
HTTP失敗・0記事・解析失敗は「募集なし」に置換しません。403/429は回避しません。
成果物は取得記録・抽出値・OCR原文だけです。画像・HTMLは一時領域から削除し、アップロードしません。
応募・ログイン・本人認証は実行せず、個別商品の応募URLは未確認のままです。

既知画像の照合: 2026-09-29案内の2商品について、2026-10-11 JSTに開発側で画像を新規HTTP取得。
締切10/5 16:59、発表10/14 15:00以降と17:00以降、注文期限10/20 16:59を目視と照合。
受付中案件としては扱いません。保存OCRのテストは再生であり、GitHub実取得の証拠とは区別します。
