# カードラボの限定実取得

公式ポケモン一覧 `https://www.c-labo.jp/tcg/pokemon/` に掲載された、タイトルにポケモン/ポケカと抽選を含む最新3個別記事を対象にします。全店舗・全記事を網羅する巡回ではありません。一覧・買取・大会・結果発表だけのページは採用しません。

通常HTTPでrobots、一覧、個別記事、公式店舗ページを取得します。Cookie・ログイン・ブラウザは使いません。許可ホスト外のリダイレクトを追わず、403/429や構造変更は失敗として停止します。記事本文の応募期間・当選発表・購入期間、Xの応募方法、店頭受取条件、公式店舗の所在地を確認します。応募対象ポストのURLは推測しません。

独立した2プロセスで20秒あけて取得し、抽出値の一致を確認してから既存スナップショットへ追加します。本文ハッシュは通信記録として保持しますが、本文の広告等が変化して抽出値が一致する場合まで失敗にはしません。必須項目が欠落した場合、0件・終了・未応募とは扱わず前回データを保持します。

年は同一期間の開始日から引き継いだ場合のみ注記します。時刻なしは補完せず、残り時間も算出しません。日付と曜日が食い違う場合は日付の数字を保持し注意を表示します。

成果物は抽出値・根拠・URL・HTTP状態・Content-Type・バイト数・SHA-256です。生HTMLやCookieを保存・公開しません。候補が一覧から消えただけでは削除せず、前回確認日時を保持します。応募済み・お気に入りの保存先には触れません。

初回はGitHubの手動/コード更新イベントによる検証です。定期実行は、実取得・照合・公開の成功確認後に設定します。テストfixtureの成功を実取得成功とは数えません。
