POKEMON RADAR 自動起動停止ツール v3

このZIPを作った時点では、あなたのPCの設定は変更していません。
GitHubの収集や公開モバイル版は操作しません。

【使い方】
1. ZIPを右クリックし「すべて展開」。ZIPの中から直接実行しないでください。
2. 1-CHECK.cmd をダブルクリック。設定は変更せず、起動登録を調べます。
   同じフォルダに autostart-check.txt を保存します。
3. CONFIRMED の実行先がポケモン専用であることを確認したら、
   2-DISABLE.cmd をダブルクリック。内容を確認して YES と入力します。
   タスクを無効化、Startup項目をバックアップ、該当Run値だけを解除します。
   POSSIBLE と SHARED は変更しません。
   変更前にバックアップと復元記録を保存できない項目は変更しません。
   管理者権限が必要な項目で失敗した場合は、2-DISABLE.cmd を右クリックして
   「管理者として実行」してください。別ユーザーの資格情報は使わないでください。
4. 結果は autostart-apply.txt にも保存されます。
   FAILED や POSSIBLE / SHARED が残る場合は、停止完了とは判断しないでください。
5. いま開いているポケモンの黒い画面は Ctrl+C で停止してください。
   本ツールは既定で実行中のプロセスを停止しません。
6. 次の通常のPCログインで、自動起動しないことを確認してください。
   本ツールは勝手に再起動・サインアウトを行いません。

CONFIRMED が0件の場合、Applyを繰り返さず、autostart-check.txt を確認してください。
その画面だけでは実際の起動元が分からないため、調査結果を元に対象を絞ります。
記録を共有する場合は、秘密情報や無関係なアカウント情報がないか確認してください。

【任意】
Chrome拡張のポケモン用自動巡回も不要なら、Chromeで chrome://extensions を開き、
POKEMON RADAR の拡張だけをオフにします。他の拡張には触れません。
4-MOBILE-SHORTCUT.cmd は公開モバイル版のショートカットを作るだけです。

【戻す場合】
3-RESTORE.cmd を実行すると、直近のバックアップから復元します。
元々無効のタスクは有効化しません。競合・破損・変更されたタスクは停止して報告します。
バックアップ: %LOCALAPPDATA%\PokemonRadar-AutostartBackup\日時\
復元先が異なる内容になっている場合、無条件に上書きしません。
変更後に処理が失敗した項目も復元対象として現状を照合します。

【対象外・限界】
他ユーザーの設定、Windowsサービス、グループポリシー、WMI等は走査しません。
共有ランチャーや実行先を証明できないPublisherは自動解除しません。
ファイル名だけの推測や node.exe の一括停止は行いません。
設定解除と、次回ログインで起動しないことの確認は別です。

【検証】
test-autostart-tool.ps1 は仮の登録データを使う開発用テストです。
あなたのPCで実行する必要はありません。
Windowsの実機適用・再ログイン確認は、利用者のPCでのみ確認できます。
