# AmazonをPCで確認してスマホへ共有

これは既存のPOKEMON RADAR取込拡張1.19.25向けの追加ファイルです。

ZIPを解凍し`APPLY-AMAZON-BRIDGE.cmd`をダブルクリックしてください。既存のChrome拡張フォルダを設定から探し、確認済みの版と一致する場合だけ4ファイルを追加・更新します。見つからない場合は`chrome-extension`フォルダの選択画面が出ます。元ファイルを先に控えます。最後にChromeの「拡張機能を管理」でPOKEMON RADAR取込の再読み込みを押します。

manifestや権限、既存のpopup.js、巡回・DBは変更しません。Windowsの適用スクリプトは未実機確認です。手作業の場合は`popup.html`、`amazonBridgePopup.js`、`amazonBridgeCapture.js`だけを同じ拡張フォルダへ配置し、再読み込みしてください。

1. PCのChromeでAmazonの個別商品ページを開く。
2. 既存のPOKEMON RADAR取込拡張を開き「Amazon案件をスマホと共有」を押す。
3. 開いた個人用画面で「この確認結果を保存する」を押す。
4. スマホで同じ個人用URLを開く。表示中なら最大30秒または開き直しで反映。

ChatGPTへのログインが必要です。初回は先に個人用画面へログインしてからAmazon側で実行してください。認証時に送信内容が失われた場合も、Amazonでボタンを押し直せば送れます。トークン入力やJSONのコピーは不要です。

保存されるのは商品名・ASIN・確認日時・商品欄の4条件の確認結果だけです。生HTML、Cookie、アカウント情報は読み取り・送信しません。確認内容はURLのフラグメントで個人用画面へ渡し、保存後に取り除きます。応募は実行しません。応募済み・お気に入りは別の操作です。

これは本人のブラウザ確認記録です。サーバーで検証した実HTTP取得や定期自動巡回とは扱いません。過去の確認を現在の受付中と断定しません。商品の構造が変わったり、中古欄・第三者販売元・無効ボタンなら停止します。CAPTCHA等は回避しません。

Windows/実Chrome上でこの追加ボタンを動かす検証は未実施です。開発側のテストは模擬DOMとSQLiteによるものであり、実機成功の証拠ではありません。


## Amazon検索から候補を巡回（PoC）

Amazon検索結果ページ（例: 「ポケモンカード 抽選」「ポケモンカード 招待」）で拡張を開き、「Amazon検索結果から候補を巡回」を押すと、可視検索結果から最大12件のASIN候補を抽出します。その後、同じログイン済みChromeで各商品詳細をバックグラウンドタブに順番に開き、既存の厳格なAmazon判定を実行します。

検索結果は候補発見専用です。検索文言だけで案件化しません。商品詳細で、対象ASIN、ポケモンカード商品名、Amazon.co.jp販売元、招待販売案内、可視かつ有効な招待リクエスト操作がすべて確認できた場合だけ候補として扱います。

確定した候補は、既存の単件 `#amazon-capture` 形式で個人用画面を開きます。個人用画面側の既存取込方式を変更していないため、各画面で「この確認結果を保存する」を押してください。

Cookie、アカウント情報、生HTMLは保存・送信しません。CAPTCHA回避、ログイン突破、招待リクエストの自動クリックは行いません。Windows実Chromeでの検索→商品巡回はまだ実機未確認です。
