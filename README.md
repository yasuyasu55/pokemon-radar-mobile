PC・スマートフォンで閲覧できる抽選情報ページです。文字サイズ、補足情報の非表示、折りたたみ検索、受取方法の複数選択に対応します。表示設定はブラウザ内に保存します。

## 自動更新

お宝創庫グループのお知らせ一覧1ページと、対象記事最大5件を通常HTTPで取得します。毎日7:17ごろ（日本時間）のGitHub Actions実行を設定しています。実行時刻はGitHub側の混雑等で遅延する場合があります。

独立した2プロセスで取得し、取得・必須項目の抽出・2回の比較がすべて合格した場合だけ、snapshot.jsonをコミットして公開します。取得失敗、抽出不完全、比較不一致、取得上限による未確認、空結果では前回の公開データを置き換えません。一覧から消えた既存案件も、最後の確認値と取得日時を保持します。

生HTML・Cookie・通信ヘッダ・認証情報・PC側DBは公開成果物へ含めません。スナップショットには公式URL、抽出値、短い根拠、HTTP状態・Content-Type・応答SHA-256等を保存します。各更新の工程と結果はActionsのログ・サマリーで確認できます。

画面は起動時、画面への復帰時、表示中は5分ごとに公開スナップショットを読み直します。通信に失敗した場合は表示中の情報を保持します。応募状態は現在日時から計算し、応募期間不明を受付中と扱いません。

同期画面は表示中30秒ごと・画面復帰時に同期します。通信失敗時は未同期と表示し、変更を端末に保留して再試行します。お気に入りだけ・未応募だけの絞り込みは他の検索条件と併用できます。取得データの更新では個人記録を消しません。ブラウザ内保存が使えない場合は警告を表示します。
